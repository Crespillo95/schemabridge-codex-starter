# Submission checklist

## Repository

- [ ] Public repository.
- [ ] Apache 2.0 detected and visible.
- [ ] Final disclosure of AI assistance and third-party components.
- [ ] No secrets or employer data in current tree or Git history.
- [ ] Exact setup, run, test, reset, and troubleshooting instructions.
- [ ] Architecture and security documents match implementation.
- [ ] `examples/` contains real outputs generated by the final build.
- [ ] Release tag and commit hash recorded.

## Functionality

- [ ] Full north-star flow works from a clean environment.
- [ ] DataHub read, write, and reuse are visible.
- [ ] Logical concepts and join contract are approved.
- [ ] Guided and natural-language requests produce equivalent plans.
- [ ] Fanout is detected and mitigated.
- [ ] Unsafe identifiers are rejected visibly.
- [ ] SQL guard and database read-only controls pass.
- [ ] Deployment is available and free to judges.

## Evaluation

- [ ] Ground truth is checked in.
- [ ] Evaluation command is documented.
- [ ] Metrics are reproduced from the release commit.
- [ ] Limitations and failed cases are disclosed.
- [ ] Screenshots and charts use real measured numbers.

## Devpost content

- [ ] Project name: SchemaBridge.
- [ ] Category: Agents That Do Real Work.
- [ ] Elevator pitch updated to final behavior.
- [ ] About section is in English and uses completed-tense claims only for implemented features.
- [ ] Built-with tags match actual dependencies.
- [ ] Live URL and public repository URL work in an incognito browser.
- [ ] Video is public, under three minutes, and readable without audio alone where practical.
- [ ] No copyrighted music or unapproved third-party marks/assets.
- [ ] Sample outputs are linked or easy to find.

## Judge comprehension test

Ask a person unfamiliar with the project to answer after seeing only the README/video:

1. What problem does SchemaBridge solve?
2. Why is DataHub essential?
3. How is it different from existing text-to-SQL?
4. What prevents unsafe or wrong SQL?
5. What concrete result did the demo produce?

Revise the submission if any answer is unclear.
